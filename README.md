# PlacementsMentoring

## About

SastraPlacements is a mentorship platform developed for SASTRA University students. It helps juniors connect with seniors for placement guidance, interview preparation, and career support.

## Features

- Junior Registration & Login
- Senior Registration & Login
- Email OTP Verification
- Forgot Password
- Mentor List
- Mentor Profile
- Community Discussion
- Notifications
- Profile Settings
- Responsive Design
- Dark Mode

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- PostgreSQL
- Nodemailer
- Socket.IO

## Installation

```bash
npm install
node server_reg.js
```
